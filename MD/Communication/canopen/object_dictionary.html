Object Dictionary#

Complete reference for object dictionary revision 1.2. The machine readable version is md_1.2.eds, available from Downloads.

The dictionary is split into three ranges:

  • 0x1000 to 0x1FFF, communication area. CiA 301 objects: identification, heartbeat, SYNC and PDO configuration.

  • 0x2000 to 0x5FFF, manufacturer specific area. MAB objects: motor parameters, encoders, controller gains, status and commands.

  • 0x6000 to 0x9FFF, profile specific area. CiA 402 objects: state machine, modes, setpoints and limits.

Access types are ro read only, wo write only, rw read and write over SDO, and rww read and write over SDO or through a receive PDO. The PDO column says whether the entry can be mapped into a PDO.

Note

Ranges in the notes column are the ones the firmware enforces. They are sometimes narrower than the data type allows and, in a few places, narrower than the EDS declares. A value outside the enforced range is rejected with SDO abort code 0x06090030.
